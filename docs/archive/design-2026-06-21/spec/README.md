# 设计规格 · 总览(给 Claude Code)

> 这套 `spec/` 是**每张设计稿的逐页深度说明**:不只是「长什么样」,还包括**我们为什么这么设计、要呈现什么美学效果、有哪些你不知道就会做错的细节**。
> 配合根目录 `HANDOFF.md`(铁律 / 文案规范 / 验收清单 / 工程 backlog)一起用。

## 怎么用这套 spec

1. **动手任何一页前,先读它的 `spec/<页面>.md`,再在浏览器打开对应 `*.dc.html` 对照。** 两者不一致时,以 `.dc.html` 的实际渲染为准,spec 解释「为什么」。
2. **一次只做一页。** 顺序建议:Vocabulary → Home → Resources → Atelier → Witness → Login → NotFound → PageLoading。
3. 每页做完,用 `HANDOFF.md §10` 的验收清单逐条自检,再交人验收。
4. **细节不是装饰,是约束。** 比如背词的词必须落在 TCF/TEF/DELF B2–C1 范围 —— 这类「领域知识」你不读 spec 就不会知道,做出来就是错的。

## 全站一句话定位

一本**班级手账(Carnet de classe)**:安静、考究、书卷气。中法双语数学班的共同记忆与学习工具。
首要气质是「**一本可以安静翻阅的书**」,不是 dashboard、不是 SaaS、不是 Web3 应用。

## 贯穿全站的美学原则(每页都成立)

- **细线 + 留白,不是盒子。** 分区靠 `1px rgba(26,26,26,.14)` 细线和大留白,**不用**卡片底色 / 圆角 / 阴影盒子。
- **暗红只做强调。** `#8b0000` 只用于:数字、语言标、强调词、主操作、当前导航项。不铺底、不大面积。
- **衬线大字做焦点。** 每屏有一个明确的视觉主角(焦点词 / 标题 / 公式),用大号衬线撑起来,周围留白。
- **零 emoji、零渐变、零卡通色。** 反馈的绿/红是仅有的功能色,且必同时带 ✓/✗ 符号。
- **三种字各司其职:** EB Garamond(法语/正文衬线)· Noto Serif SC 思源宋体(中文标题)· JetBrains Mono(数字/键帽/元信息/技术标)。
- **双语并置:** `中文 · Français`。法语常作斜体引文或眼标,中文作标题与正文主体。
