# 班级寄语墙 SolanaWitness —— 深度规格

> 真实文件:`src/pages/SolanaWitness.jsx` · 路由 `/witness`(原 `/hackathon` 系)
> 链上逻辑(`@solana/web3.js`、SPL Memo、自写 Anchor 程序 `class_anchor`)逐字保留。

## 我们的核心决策 —— 最重要的一条

**把区块链黑话全部翻译成人话。技术是脚注,不是主角。**
这一页原本是黑客松的「Solana Witness」陈列页,堆满 `Program ID / PDA / devnet / memo / Anchor / Connect Phantom`。
用户(班级同学)看不懂、觉得抽象。我们重构成一面**「班级寄语墙」**:讲的是「给这个班留一句话」这件具体的人事。

**翻译对照(照此,别还原成黑话):**

| 技术原话 | 人话(用这个) |
|---|---|
| Solana Witness | 班级寄语墙 |
| Anchor a statement / 上链 | 写下你的寄语 / 留下这句话 |
| Connect Phantom wallet | 连接钱包(钱包就像你的署名) |
| Program ID / Cluster / Framework | 三个品质:永久保存 · 公开可见 · 不可篡改 |
| Signature / PDA(收据) | 凭证 / 核验 |
| Status: Confirmed | 状态:已永久保存 |

技术信息只保留**一行灰色脚注**:「由 Solana 区块链承载 · 程序 Cmv8pnx…BC4fu · MIT 开源」。

## 结构(全部居中)

1. 顶部页头 + 返回协作。
2. **报头**:眼标「Pour la classe · 班级寄语」→ h1「班级寄语墙」→ 一句人话说明(「给这个班留下一句话 —— 一句你想被记住的话。写下后它就一直留在这里,谁也改不了、谁也删不掉。」)。
3. **三个品质**(细线带 + 居中三列):永久保存 / 公开可见 / 不可篡改,各配法语小标(Permanent / Public / Inaltérable)+ 一行灰色技术脚注。
4. **01 先连接你的钱包**:说明「钱包就像你的署名」+ 连接按钮 + 没钱包的引导链接(装 Phantom)。连接后显示「● 已连接 · 钱包尾号」。
5. **02 写下你的寄语**:文本框(最多 80 字,实时中文字数计数)+ 「留下这句话」按钮 + 成功后的人话收据(状态/凭证/核验)。
6. **03 已经留下的话**:留言列表(每条:话居中 + 时间 · 核验链接)。
7. 细页脚。

## 关键细节

- 字数限制按**字符**(80 字),不是字节;实时「还能写 N 字」。
- 没装钱包**不能是死路**:给「两分钟装好 Phantom」引导链接(免费浏览器插件)。
- 真实化要处理三态:提交中 / 失败 / 成功;可加「只读浏览」(不连钱包也能看大家的话)。
- 收据用人话标签(状态/凭证/核验),哈希降为灰色,只留一条 Solscan 链接。
- 全页**居中**(Léo 明确要求)—— 标题、说明、输入框、留言列表都居中。

## 美学落点

像一面安静的纪念墙:三个品质用思源宋体并置、留言用衬线居中陈列;区块链的存在感被压到一行灰脚注。情感在前(给班级留句话),技术在后(它恰好刻在公链上)。

## 易错点

- ❌ 还原任何区块链黑话到用户可见处 → 全说人话。
- ❌ 把技术参数(Program ID/PDA…)做成显眼的数据面板 → 降为一行灰脚注。
- ❌ 左对齐 → 全页居中。
- ❌ 没钱包就卡死 → 给安装引导。
- ❌ 用「孄語」等乱码字 → 是「寄语」。
