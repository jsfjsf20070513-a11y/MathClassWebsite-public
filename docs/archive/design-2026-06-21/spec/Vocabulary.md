# 背词 Vocabulary —— 深度规格

> 真实文件:`src/pages/Vocabulary.jsx` · 路由 `/vocabulary`
> 纯逻辑:`src/lib/srsScheduler.js` / `vocabularyBackend.js` / `vocabularyProgress.js`(94 个单测,逐字保留)
> 这是全站**最容易做错**的一页。原型 UI/交互是契约;判分与调度接真实逻辑。

---

## 1. 我们的核心设计决策(为什么这么做)

**① 不做「自评」,做「主动回忆测试」。**
最早的版本是「看词 → 自己点记住了/没记住」。**这是错的** —— 自评是最弱的记忆方式。
改成**主动产出**:系统出题,你打出答案 / 选答案,客观判分。这是 retrieval practice(测试效应),记忆留存最强。
→ 所以这一页本质是**一场测验课**,不是翻卡片。

**② 先学一遍,再测(Léo 的要求)。**
直接上来考试会挫败。所以一节课分两段:**预习(Aperçu)** → **测试(六题型)**。
预习阶段逐词过一遍词典卡(法语词 + 词性 + 等级 + 中文 + 例句),可「跳过预习,直接测试」。

**③ 多题型轮换(百词斩 / 多邻国机制)。**
同一个词用不同模态反复命中,才记得牢。六种题型轮流出:

| 题型 | 提示 | 作答 | 练什么 |
|---|---|---|---|
| 配对 Associez | 法↔中四对 | 点连 | 开场热身、快速激活 |
| 认词 Quel est le sens ? | 大字法语词 | 选中文(4 选 1) | 法→中识别 |
| 词块拼句 Traduisez la phrase | 中文句 | 点词块拼出法语句 | 语序、句法 |
| 例句填空 Complétez la phrase | 挖空例句 | 选词(4 选 1) | 搭配、性数变化 |
| 听写 Écoutez et choisissez | 法语发音 | 选词(4 选 1) | 听辨 |
| 拼写 Écrivez en français | 中文词 | 打出法语 | 最强主动产出 |

**④ 反馈必须一眼可辨(踩过的坑)。**
最早答对用暗红、答错用灰,分不清。**现在:答对=绿 `#3f7a4e`、答错=暗红**,且**必带 ✓/✗ 符号**(色盲也能辨)。
答对绿底横幅「答对 ✓ Juste」;答错红底横幅「答错 ✗ Faux」+ **大字给出正确答案**。还有极轻的 WebAudio 提示音(对:上扬两音;错:低沉两音)。

## 2. ⚠️ 词库:必须是 TCF / TEF / DELF B2–C1 范围(你不读这条就会做错)

**这一页不是给初学者背 livre / école 这种简单词的。** 目标用户是要考 **TCF / TEF / DELF-DALF B2–C1** 的学生。
词必须落在这个难度区间 —— 抽象名词、高阶动词、书面语形容词。原型 18 条种子词(照抄,别替换成简单词):

```
l'essor 腾飞 · entraver 阻碍 · la pénurie 短缺 · insidieux 阴险/潜移默化 ·
l'aval 同意/批准 · éphémère 短暂 · la mainmise 控制/把持 · prôner 鼓吹 ·
l'engouement 热衷/追捧 · fustiger 严厉抨击 · probant 有说服力的 · le clivage 分裂/对立 ·
entériner 批准/正式认可 · escompter 期望/指望 · lacunaire 有缺漏的 ·
pérenne 持久的 · le truchement 媒介/中介 · désormais 从此/今后
```

**接真实词库时的硬约束:**
- 词源必须标注考试范围(TCF/TEF/DELF + B2 或 C1),并能按等级筛选(原型底部「全部 / B2 / C1」)。
- **不准**为了凑数掺入 A1–B1 的简单词。难度跌下来,这页就失去意义。
- 每个词要有:`french`(带冠词形式如 `l'essor`)、`answer`(判分用的裸词 `essor`)、`pos` 词性、`level`(B2/C1)、`chinese`、`example`/`cloze`(真实语境例句)。

## 3. 判分规则(细节,做错就恼人)

- **拼写/拼句判分忽略大小写与音符**:`pénurie` 打 `penurie` 算对;裸词比较时去掉冠词(`l'/le/la/les/un/une/des`)。原型 `norm()` 函数就是干这个的,照搬。
- **干扰项(选项题的错误选项)**:优先取**相同词性、相近长度**的词,别随机乱配 —— 难度才合理。
- **错词进复习**:本轮答错的词收集起来,结算页可「只练错词」。接真实 SRS 后,错词进「重学」队列,跨天回考。
- **连击**:连续答对累加,右上角显示「连击 ×N」(N≥2 才显示)。

---

## 4. 键盘 / 焦点(交互细节,缺了就不顺手)

- 选项题:`1–4` 选项,`回车/空格` 在反馈态进入下一题。
- 拼写/拼句:`回车` 判分。
- 输入框**自动聚焦**:进入拼写题时光标已在输入框,打字→回车→打字→回车,全程不碰鼠标。
- 预习态:`回车/空格` 翻下一词。

---

## 5. 状态(全都要,别漏)

`study`(预习)· `ready`(答题:含六题型 + 反馈)· `done`(结算:已斩 N 词 + 正确率 + 最高连击 + 错词清单 + 只练错词/再来一轮)·
`loading` · `empty` · `error` · `disabled`(未配 Supabase)· `compat`(数据表未建)· **未登录**(进度按账号存,提示登录)。

## 6. 音频(听写题)

原型用浏览器 `speechSynthesis`(设备音质不稳,仅占位)。
**真实化:改用 ElevenLabs 预生成 mp3**(roadmap 已有,API key 只在构建期、不进打包产物)。WebAudio 提示音需用户首次交互后 `resume()`,确保首次答题能出声。

## 7. 美学落点(这页长什么样、为什么)

- 顶部一条**细进度条** + 右侧连击数 —— 给「往下走」的动力,但极克制(2px 高)。
- 答题区**居中**,焦点(法语词 / 中文词 / 例句)用大号衬线撑起,周围大留白 —— 「专注做一道题」的仪式感。
- 工具(等级筛选、词数)**降到最底**,安静地放在一条细线下 —— 别让工具抢了词的主角位。
- 反馈横幅是**唯一**出现底色块的地方(绿/红淡底),且带 220ms 淡入 —— 因为「对/错」是这页唯一需要强反馈的时刻。
- 全程衬线 + 细线 + 暗红,零 emoji、零卡通色。绿色 `#3f7a4e` 是和暗红同明度的克制绿,不跳。

## 8. 易错点清单(你最可能犯的错)

- ❌ 把词换成简单词 → 必须 B2–C1。
- ❌ 把六题型砍成「翻卡片」→ 题型轮换是核心机制。
- ❌ 反馈只用颜色不用符号 → 必带 ✓/✗。
- ❌ 答对用红、答错用灰 → 答对绿、答错红。
- ❌ 删掉预习直接考 → 先学后测。
- ❌ 给卡片加圆角盒子/底色 → 细线 + 留白。
- ❌ 判分不忽略音符 → `penurie` 必须等于 `pénurie`。
- ❌ 工具栏放顶部抢戏 → 降到最底。
