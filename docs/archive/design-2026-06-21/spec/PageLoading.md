# 加载页 PageLoading —— 深度规格

> 真实文件:`src/components/PageLoading.jsx` · 每次路由切换 / 初次启动显示

## 我们的核心决策

**加载页是重灾区,重做成碩卷式安静加载。**
旧版有**发光球(orbs)+ 渐变氛围层 + 每路由不同调色板 + 十来个元素**(badge/motto/eyebrow/title/quote/note/meter/ledger…)——
典型的「AI 渐变光晕 + 信息过载」slop,和书卷气完全冲突。**全删。**

新版只有三样东西:**一句双语引文 + 一条细扫光进度线 + mono 计数**。零光晕、零渐变。

## 结构(居中)

1. 眼标(按页:扉页 · Accueil / 背词 · Vocabulaire / 资源 · Ressources)。
2. **法语斜体引文**(暗红)在上 → **中文**(思源宋体)在中 → 一行灰色加载注。三者每次淡入。
3. 一条 140px 细线 + 暗红扫光(`pl-sweep` 动画来回扫)+ mono 计数(01 / 03)。

## 关键细节

- 句子**按页轮换**(扉页/背词/资源各有不同句子池),每 2.2s 换一句,淡入。
- 双语:法语斜体在上、中文在下 —— 和全站双语调性一致(这是后补的,Léo 要求加法语)。
- 扫光进度线是**不确定型**(来回扫),因为加载时长未知,不是百分比进度。

## 美学落点

一页安静的过场:暗红法语引文 + 中文,一条克制的扫光线。和首页扉页同源的书卷气,让「等待」也像在翻书的间隙,而不是盯着一个加载动画。

## 易错点

- ❌ 加回发光球 / 渐变 / 每路由调色板 → 全删,只留引文 + 细线。
- ❌ 只有中文没法语 → 双语,法语在上。
- ❌ 做成百分比进度条 → 不确定型扫光。
