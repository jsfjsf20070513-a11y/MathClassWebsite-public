# 登录 Login —— 深度规格

> 真实文件:`src/pages/Login.jsx` · 路由 `/login` · 接 Supabase Auth(仅 anon key + RLS)

## 我们的核心决策

**登录必须有清晰的「为什么要登录」。** 早期文案是「进入协作记录与班级工作台」—— 工作台都删了,理由站不住。
重新锚定到两个**具体好处**:
1. **背词进度跨设备同步** —— 手机上背的,电脑上接着背。
2. **班级 AI 助手** —— 双语数学答疑,登录后可用(即将开放)。
登录态下,这两条用 ◆ 小点列在标题下方,让价值看得见。

## 结构(居中)

1. 顶部页头(只有字标,无导航 —— 登录是独立流程)。
2. **报头**:返回扉页链接 → 眼标「AUTHENTIFICATION」→ h1(随模式变:登录·Connexion / 注册·Créer un compte / 验证码登录·Code / 找回密码·Mot de passe oublié)→ 一句 summary。
3. **两条好处点**(仅登录模式显示):◆ 背词同步 / ◆ AI 助手。
4. **模式 tab**:登录 / 注册 / 验证码 / 找回密码(暗红下划线选中)。
5. **方式 tab**(仅登录/注册):邮箱 / 手机。
6. **表单**(整列居中,字段随模式增减):真实姓名·Nom / 昵称·Pseudo / 邮箱·E-mail / 手机号·Téléphone / 密码·Mot de passe / 确认密码·Confirmer / 验证码·Code。输入框是**细下划线**(无边框盒子),文字居中。
7. 主操作(下划线文字按钮)+ 法语冥想尾句 + 中文翻译。

## 关键细节(踩过的坑)

- **零英文 UI 文案**:全部 `中文 · Français`。别写 Sign in / Email / Password(已清理,别还原)。
- 手机号输入框**不放 placeholder**(「11 位手机号」破坏留白,Léo 指出过)—— 留空,靠 label。
- 法语冥想尾句**必须有中文翻译**(Léo 指出过):「门只是门槛 —— 真正要紧的,是你走进的那间屋子。」
- 输入框是细下划线 + 居中文字,**不是**方框输入框。
- 真实化补:邮箱格式 / 密码强度 / 两次密码一致 / 手机号 11 位的即时校验;验证码 60s 倒计时;登录成功给去向选择(去背词 / 去寄语墙)。
- 窄屏四个模式 tab 会换行,建议改下拉 select。

## 美学落点

整个表单**居中**(早期表单左对齐、报头居中,显得歪 —— Léo 指出后已全居中)。细下划线输入框 + 大留白,像在一张素净的纸上填字。暗红只在选中 tab、主操作、◆ 点上。

## 易错点

- ❌ 英文标签(Sign in/Email/Password)→ 中文·法语。
- ❌ 表单左对齐 → 全居中。
- ❌ 手机号放 placeholder → 留空。
- ❌ 法语尾句无中文 → 必配翻译。
- ❌ 方框输入框 → 细下划线。
- ❌ 登录价值含糊 → 两条具体好处。
