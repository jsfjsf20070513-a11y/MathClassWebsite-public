# 404 NotFound —— 深度规格

> 真实文件:`src/pages/NotFound.jsx` · 路由 `*`

## 我们的核心决策

**404 也要有书卷气和班级气质,不是冷冰冰的报错。** 用一句**数学比喻**承接调性,再给出口,别让用户走进死路。

## 结构(居中)

1. 顶部页头(只字标)。
2. 居中:mono「404」→ h1「页面未找到」→「Page not found」。
3. **数学比喻**(法语斜体 + 中文):「Comme chercher sur la droite réelle un point qui n'existe pas. / 这就像在实数轴上寻找一个并不存在的点。」
4. 细线分隔 → 「也许你在找:」+ 三个出口链接(资源·书目 / 背词 / 协作)→ 返回扉页(次级链接)。

## 关键细节

- 三个出口链接 `white-space:nowrap`,别折行。
- 比喻句是这页的灵魂,保留。
- 真实化:出口链接接真实 `<Link to>`。

## 美学落点

居中、克制,一句数学比喻把「找不到」说得有文化;三个出口给台阶,不留死路。

## 易错点

- ❌ 做成冷冰冰报错页 → 保留比喻 + 出口。
- ❌ 只有「返回首页」一个出口 → 给三个 + 返回。
