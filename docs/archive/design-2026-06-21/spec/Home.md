# 扉页 Home —— 深度规格

> 真实文件:`src/pages/Home.jsx` · 路由 `/`

## 我们的核心决策

**这是一本书的扉页,不是 landing page。** 访客第一眼应感到「翻开了一本班级手账」,而非「进了一个产品官网」。
所以:**没有** hero 大图、**没有** CTA 按钮墙、**没有** 功能卡片网格。只有封面题署 + 一则每日定理 + 一句冥想。

**全站地图交给顶部导航,不在首页重复。** 早期版本首页铺了课表、图版、阅读线、还有一个 Sommaire 目录 —— 全删了,因为:
- 课表/图版已下线;
- Sommaire 和顶部导航重复,「难怪觉得没用」。
→ 引导是结构性的(完整导航 + 安静首页),不是堆一地入口。

## 结构(从上到下)

1. **顶部页头**(全站统一):`CARNET DE CLASSE` 字标 + 四项导航(当前页「扉页」暗红下划线)+ 右侧登录。
2. **封面题署**(居中):眼标「中国人民大学中法学院」(暗红小字大写)→ h1「2025 级数学班」(思源宋体 40px)→ 法语斜体副题「Trente mathématiciens, une classe.」→ mono 版本日期。
3. **每日定理**(居中,细线分隔):眼标「Rappel mathématique · 每日定理」→ 定理名(Bolzano–Weierstrass)→ 中文一句话陈述 → **KaTeX 渲染的公式** → 折叠的「查看证明思路」(展开是中文 + 法语双栏,①②③④ 编号步骤)。
4. **一句冥想**(居中,细线分隔):法语斜体 + 中文。
5. **细页脚**:`Pour la classe.` + 安静的「班级寄语墙 →」链接。

## 关键细节(不读会做错)

- **KaTeX 必须真渲染**,不是 Unicode 拼凑。原型用 `katex.render(expr, el, {displayMode:true})`。移植时建议**构建期 `renderToString` 预渲染**(首页只一个公式,没必要运行时加载整个 KaTeX JS)。公式见原型 `bw-formula`。
- **每日定理应做成轮换池**:你们已有 24 条带中法证明的定理。原型里 Bolzano–Weierstrass 是占位,真实化时每天轮换。冥想句同理。
- **证明分中文 / 法语双栏**,各 ①②③④ 步,套用 `.theorem-explanation-block` + `.theorem-explanation-lang` 类。
- 版本日期 `Édition du 20 juin 2026` 是硬编码占位,接真实日期。

## 美学落点

封面居中、大留白,像翻开扉页的第一眼;每日定理是首页唯一的「活内容」,用 KaTeX 公式做视觉焦点;整页三段之间用细线 + 80px 大留白分隔,节奏从容。零盒子、零 emoji。

## 易错点

- ❌ 加 hero 图 / CTA 按钮 / 功能卡网格 → 这是扉页,只有题署+定理+冥想。
- ❌ 把课表/图版/目录搬回首页 → 已删,引导靠导航。
- ❌ 公式用 Unicode 拼 → 必须 KaTeX。
- ❌ 定理写死一条 → 应轮换池。
