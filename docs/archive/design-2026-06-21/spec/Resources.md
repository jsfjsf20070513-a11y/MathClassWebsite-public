# 资源 Resources —— 深度规格

> 真实文件:`src/pages/Resources.jsx` · 路由 `/resources` · 数据 `src/data/resourceCatalog.js`

## 我们的核心决策

**像一部「书目 / 书架」,不是链接列表。** 资源是 77 条外部学习资源(MIT OCW、Exo7、3Blue1Brown、CNRTL…),分 8 个书架。
设计成**编号书架 I–VIII**(罗马数字),每条目是「标题 → 来源 + 暗红 mono 标签」的细线行 —— 像翻一部考究的书目,而非点一堆链接。

**删掉了 Appendix。** 早期版本末尾有个 Appendix 重新罗列所有条目 —— 纯重复,删。同样的「less is more」纪律。

## 结构

1. 顶部页头(当前页「资源」高亮)。
2. **报头**(居中):眼标 `BIBLIOTHÈQUE` → h1「资源与书目」→ 法语斜体引文 + 中文。
3. **书架索引**:I–VIII 的可跳转目录(罗马数字 + 书架名 + 条数),点击锚点跳到对应书架。
4. **八个书架**:每架 = 罗马数字 + 思源宋体架名 + 细线分隔的条目列表。每条目:标题(外链,暗红细下划线)→ 右侧暗红 mono 标签(如「分析」「实分析」「直观」)→ 下方一行中文简介。

## 关键细节

- **数据单一来源**:全部来自 `resourceCatalog.js`,页面只渲染。**别**把简介写死在 JSX 里两份。
- 外链全部 `target="_blank" rel="noopener noreferrer"`。
- 书架索引跳转用锚点 + `scroll-margin-top`(防被固定页头遮挡,若页头将来固定)。
- 77 条是真实精选资源,**别精简、别替换**成示例链接。
- 条目结构:`标题 / url / 标签 / 简介` 四字段。

## 美学落点

罗马数字 + 思源宋体架名给出「卷册」感;细线分隔每条,大量留白;暗红只出现在标签和外链下划线上。整页像一份排印讲究的参考书目,安静、可长时间浏览。

## 易错点

- ❌ 做成卡片网格 → 是细线书架行。
- ❌ 简介写死在两处 → 单一数据源。
- ❌ 加回 Appendix → 已删。
- ❌ 精简 77 条 → 全保留。
