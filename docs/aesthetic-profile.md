# 审美档案(用户视觉品味 · 以实例为证)

用户不擅长用语言表达审美,这份档案由代理替他把"脑里的感觉"翻译成可执行的语言,
并**用本项目里他亲口拍板的实例不断校准**。做任何视觉件先按此锚定,出实物后按他
"对 / 不对"收敛;推歪了让他纠,纠了就记回这里。

## 主轴(按优先级)

1. **反混乱(总原则)**:一切先服从"不乱"。信息分层、对齐、留白,一眼抓到秩序;
   宁可少、不可杂。
2. **和谐成体系**:配色成体系、字号成阶梯、间距成倍数、动画成体系(同一条缓动曲线、
   同一套侧倾投影);局部服从整体,没有哪处跳出来打架。
3. **节奏**:有呼吸的排布——**一页一停,一件一件呈现**,刻意的先后顺序,不一次堆满。
   浓淡交替本身是节奏(封面浓、内页疏)。
4. **质感**:细腻层次、考究间距、耐看细节;低调但摸得出质量;不要廉价大色块扁平。
5. **简约**:每个元素都有用途,能减则减;**讲不出道理的装饰就是杂**。
6. **构图**:平衡、主体明确。居中是常用手段但**不是教条**(见修正记录 #1)。
7. **配色**:低饱和、冷淡、克制(莫兰迪/中性/暖纸暖墨);红只作朱批与活性信号。

## 雷区

混乱杂糅 · emoji 堆砌 · 花哨动画(≠有编排的动画,见实例 4)· 高饱和撞色 ·
渐变紫 AI 味 · 廉价扁平 · 过度可爱 · **随意不对称**(长短不齐的双列、参差的留白)·
装饰性复读(同一强元素反复出现直至稀释)· 元数据堆叠(一屏多条计数各说各话)。

## 本项目实例(2026-08-20 杂志刊改版合议)

1. **"Home 设计稿我很满意"** —— 满意的对象:5 页横翻图录、60 人肖像墙封面、
   页页不同的纸色分层、翻页四方向编排、data-animate 逐件进场、常驻 folio、
   天气 canvas 的克制粒子。→ 这是他心中"对"的基准件,后续视觉件向它对表。
2. **"这三个内页有点杂乱,需要精简"** —— 病灶确诊并获认可:①肖像装饰复读
   (内页邮票/守护人带,映射讲不出道理);②元数据堆叠(一屏四条计数);
   ③常驻筛选器打扰主任务。→ 立为宪法三大禁令。
3. **"居中有点死板了"** —— 修正:居中是手段不是目的。一页内允许编辑式不对称
   (大词在左、选项在右),只要该页只有一个主角、构图自平衡。
   秩序感的真正来源是**编排**(一页一停 + 统一翻页物理 + 常驻锚点),不是中轴线。
4. **"Home 的节奏非常好,一页一停;内页也要多拆分,注意衔接动画"** ——
   他不反对动画,反对的是**无编排的动画**。有方向、有先后、成体系的动画
   (翻页轻重分级、发丝线自上而下画出、逐件错开淡入)正是他要的质感与节奏。
   衔接(跨路由翻页、无白幕)与页面本身同等重要。

## How to apply

- 新视觉件:先读本档案与 `design-constitution.md`,按主轴出**实物**(不是方案描述),
  给他看,按"对/不对"收敛。
- 他的反馈往往很短("有点杂乱"/"死板了")——先诊断病根再动手,把诊断说给他听
  确认,别只对症状打补丁。
- 每次拍板(尤其是推翻旧口径的)记回修正记录,让档案随他一起演化。
